# Bulletin_Board
Дипломный проект Python/Django REST Framework
## Описание
Backend часть приложения "Доска объявлений".
## Фунционал проекта
1. Авторизация и аутентификация пользователей.
2. Распределение ролей между пользователями (пользователь и админ).
3. Восстановление пароля через электронную почту.
4. CRUD для объявлений на сайте (админ может удалять или редактировать все объявления, а пользователи только свои).
5. Под каждым объявлением пользователи могут оставлять отзывы.
6. В заголовке сайта можно осуществлять поиск объявлений по названию.

### Эндпоинты приложения пользователей
* Регистрация пользователя. Необходима верификация email.
* Аутентификация пользователя.
* Просмотр своего профиля. Администратору доступны все профили.
* Изменение своего профиля. При смене email, также необходима верификация.
* Верификация email. Доступны методы GET и POST.
* Сброс пароля (запрос токена для смены пароля на email).
* Подтвержение сброса пароля (проверка токена и установка нового пароля).
* Список пользователей. Доступно только администратору.
* Администрирование пользователей. Для активации или блокировки пользователей,
  а также назначения новых адмистраторов
### Эндпоинты приложения объявлений
* Список объявлений. Доступно неавторизованным пользователям. Имеется возможность фильтрации
  по диапазону цен, минимальной дате и авторам. Реализована пагинация сортировка и посковый запрос.
* Эндпоинты CRUD объявлений. Дотупно только авторизованным пользователям и администраторам.
* Список отзывов для объявлений. Доступно только авторизованным пользователям. Имеется возможность
  фильтрации по авторам и сортировка по дате. Реализована пагинация и посковый запрос.
* Эндпоинты CRUD отзывов. Дотупно только авторизованным пользователям и администраторам.
* Отправка сообщения пользователю указанного объявления с сохранением конфиденциальности.
### Эндпоинты приложения изображений
* Эндпоинты CRUD отзывов. Дотупно только авторизованным пользователям и администраторам.
  Пользователи могут добавлять, изменять и удалять фотографии только для своих объявлений,
  администраторы - для любых.
## Установка локально или на сервере
1. Клонировать проект
    ```
    https://github.com/Ramazan-Z/Bulletin_Board
    ```
2. Записать чувствительные данные в файл `.env.example` и сохранить его как `.env.`
    Необходимые данные:
        * Секретный ключ django и флаг дебага.
        * Данные для подключения к postgresql.
        * Данные для подключения к почтовому серверу.
        * Данные для регистрации суперпользователя и администратора.
        * Флаг необходимости заполнения базы данных иэ фикстур.
3. Сборка образа приложения и запуск с использованием docker
    ```
    docker compose up -d --build
    ```
4. Остановка
    ```
    docker compose up down
    ```
